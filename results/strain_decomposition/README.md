# Strain-decomposition results

Derived strain-decomposition results for the AS, SR350, SR425, SR525, and SA1150 conditions.

The workflow is implemented in `scripts/strain_decomposition.py` and uses the condition-specific FEM history CSV files stored under `data/fem_histories/`.

This directory contains the per-condition decomposition tables, summary table, figure, method note, and provenance manifests used to document and reproduce the analysis.

The strain-decomposition workflow does not require the full Exodus spatial-field databases.
