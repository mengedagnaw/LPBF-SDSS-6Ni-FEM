# Spatial field-evolution results

Post-processed spatial FEM field evolution for the AS, SR350, SR425, SR525, and SA1150 conditions.

The figures are generated by `scripts/field_evolution.py` from the corresponding Exodus databases.

The full Exodus `.e` databases are distributed separately because they exceed the normal GitHub per-file size limit. Their integrity information is provided under `data/exodus/`.

This directory contains the generated figures, selected loading-state definitions, plotting limits, analysis settings, and provenance manifests required to document the post-processing workflow.
